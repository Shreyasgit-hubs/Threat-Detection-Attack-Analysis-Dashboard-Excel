# 🛡️ Cyber Threat Detection & Attack Analysis Dashboard

> An interactive Microsoft Excel dashboard designed to monitor cyber threats, analyze attack patterns, detect anomalies, and visualize system performance using dynamic KPIs and charts.

![Dashboard Preview](images/dashboard)

---

## 📌 Project Overview

The **Cyber Threat Detection & Attack Analysis Dashboard** is an advanced Microsoft Excel Business Intelligence project that transforms raw cybersecurity data into meaningful insights.

The dashboard enables security analysts to:

- Monitor cyber attacks in real time
- Identify high-risk attack vectors
- Analyze malware trends
- Monitor IDS alerts
- Track CPU and Memory utilization
- Detect anomalies using anomaly scores
- Filter data dynamically using slicers and timelines

This project demonstrates practical skills in:

- Data Cleaning
- Data Transformation
- Data Analysis
- Dashboard Design
- Business Intelligence
- Cybersecurity Analytics

# 📊 Dashboard KPIs

The dashboard includes the following Key Performance Indicators:

| KPI | Description |
|------|-------------|
| Total Records | Total network traffic records |
| Total Attacks | Number of attack events |
| Normal Traffic | Number of normal traffic records |
| Average Anomaly Score | Mean anomaly detection score |
| Average Severity Index | Average attack severity score |
| Total IDS Alerts | Total Intrusion Detection System alerts |
| Average CPU Utilization | Average CPU usage |
| Average Memory Utilization | Average Memory usage |
| High Severity Attacks | Number of High severity attacks |
| Total Malware Records | Total malware observations |
